# PROJECT BADGER · 19

这次重做以一个连续的立体微缩街角承载完整故事。熊与树懒由 Three.js 几何模型组成，配有可动头、手臂、相机和吉他；环境、纹理、灯光和声音在本地生成。

- `main.js`：可见时间线、镜头、交互、光影接线与纪念照片。
- `song.js`：指定歌曲录音、首次触碰播放与加载状态。
- `song-timeline.js`：06:20参考cue表、选定录音元数据和实测尾奏起音。
- `song-timeline-verify.mjs`：校验导演cue顺序、边界和可调整锚点。
- `music-clock.js`：播放时跟随原曲、静音回退、缓冲和后台冻结。
- `director.js`：十二章节与42个镜头段，把长音乐时间与短动作片段分开。
- `choreography.js`：并肩、返回街角、犹豫与回应的分段走位、镜头及额外表演。
- `unfolding.js`：03:54后展开的石板、白花、窗框和光路，保持十个绘制对象。
- `score.js`：历史原创配乐模块，当前仅作受控交互音效来源，不播放旧背景旋律。
- `lighting.js`：开场、裂变、重逢和雪夜的连续光影包络。
- `characters.js`：原创角色、表情和身体动作。
- `world.js`：街道、花窗、代码外壳、碎裂、雪和探索目标。
- `photographs.js`：熊视角花窗抓拍与最终合照，共用渲染恢复和单文件照片输出。
- `template.html`：界面、字幕、声音开关及照片查看。
- `archive.js`：从原始页面和脚本生成可离线重看的完整作品，结尾显式点击后下载。
- `build.mjs`：把 Three.js 和作品打包进单文件 HTML，无外部请求。
- `verify.mjs`：使用真实 Three.js 场景图检查姿态、地面、可见性、手掌接触和不同画幅取景。
- `runtime-verify.mjs`：检查声音恢复、静音、像素预算、低动态反馈和照片失败恢复。
- `motion-verify.mjs`：逐帧检查自动/点击入场、不同画幅、人物穿插、脚底和实际拳面接触。
- `archive-verify.mjs` / `archive-roundtrip.mjs`：检查离线导出的源码安全与构建逐字节一致性。

运行 `npm ci`，然后 `npm test` 和 `npm run build`。构建输出为 `../dist/index.html`，并复制到 `../exports/PROJECT-BADGER-19-offline.html`。网站与离线副本使用同一文件。

声音需要首次用户触碰解锁；主背景音乐已指定为方大同《好不容易》，已接入用户提供的MP3；旧原创配乐仅保留交互音效能力。作品不会假定具体私人回忆，祝福仍可替换。实际 WebGL、手机触屏和系统音频应在目标设备验证。离线 Blender 预览只用于几何与构图检查，不是网页截图。

角色位移会驱动脚步；重逢后手掌在实际世界坐标接触，小光保留到合照。手机和桌面按总像素预算限制渲染缓冲，旋转设备时重新选择尺寸与阴影设置。

摄影过场将实际抓拍显影，结尾可切换并分别保存两张照片。重播会清空相册和步态缓存，捕获失败不会显示空白卡片。

成功拍下的照片不随视口变化重新生成。花窗抓拍最多尝试两次；即便合照失败，已留下的花窗照仍可查看和保存。

雪夜有一片雪落在熊的自由掌心，两只共同注视，再回望对方；最后三秒定镜。裂缝中熊稍晚回应 BADGER 的伸手，两掌接触后的两秒先安静，再让光和主题展开。主背景录音连续播放，场景变化不会跳歌或更换位置；交互音效由本地生成。

歌曲自然结束后不自动循环，普通探索不会再次启动前奏。音乐主时钟与六分钟导演适配已接入；人声锚点仍需实听核对，详见 `../docs/SONG-TIMELINE.zh-CN.md`。运行 `node ../docs/build-timeline-preview.mjs` 可重建独立的导演时间轴页面和cue JSON。
